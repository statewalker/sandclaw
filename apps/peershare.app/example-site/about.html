About this site

An example of a remote service shared with PeerShare.

This site lives at https://peershare-demo.httpeers.net: static pages, a stylesheet, an image and two JSON files, read by a script. To share it, add it in PeerShare as a service with that address. It is a remote https:// site with a domain name, so PeerShare reaches it directly, without the local proxy.

Directly means the PeerShare page itself reads this site, so the site has to allow it. Its .site/config.json lists PeerShare's origin under cors: every answer carries Access-Control-Allow-Origin, and the browser's preflight (PeerShare sends its own header) is answered.

A guest sees these pages in their own isolated origin. Every page, image and JSON file they load travels over the mesh to the sharer's browser, which reads it here. The links and the data paths are relative, so nothing points back at this address.
