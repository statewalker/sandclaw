# Notes and todos

Notes and todos are **files in the user's folder**, not a store of their own. A todo is any
Markdown checklist item (`- [ ] …`) in any file: a meeting note, a client file, the
`Notes/todo.md` inbox. Ticking an item edits that line in its file, so the assistant, the folder
and the list never disagree. New todos typed here go to `Notes/todo.md`; **New note** creates a
dated Markdown file in `Notes/`. A conversation can also be saved as a note from the assistant
panel.
